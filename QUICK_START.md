# ⚡ Quick Start Guide

**Need to get started RIGHT NOW? Follow these steps:**

## 1️⃣ Install & Run (5 minutes)

```powershell
# Open PowerShell in this folder, then run:
npm install
npm start
```

✅ Your website will open at `http://localhost:3000`

---

## 2️⃣ Deploy to GitHub (10 minutes)

```powershell
# First time only - set up Git:
git init
git add .
git commit -m "Initial commit"

# Connect to GitHub (replace with YOUR repo URL):
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git branch -M main
git push -u origin main
```

📖 **Full instructions:** See `DEPLOYMENT_GUIDE.md`

---

## 3️⃣ Deploy to Netlify (2 minutes)

1. Build: `npm run build`
2. Go to [netlify.com](https://netlify.com)
3. Drag the `build` folder onto Netlify
4. Done! 🎉

📖 **Full instructions:** See `DEPLOYMENT_GUIDE.md`

---

## 📚 Project Structure

```
src/
  components/    ← All website sections (Navbar, Hero, etc.)
  App.js        ← Main app file
  index.js      ← Entry point
```

## 🛠️ Common Commands

- `npm start` - Run development server
- `npm run build` - Create production build
- `npm install` - Install dependencies (first time only)
